하이스케치 데모 실행 방법
================================

■ 준비 (컴퓨터에 1회만)
  - Node.js 설치 필요: https://nodejs.org  → "LTS" 버전 다운로드 후 설치
    (이미 설치돼 있으면 건너뜁니다)


■ 실행
  1. "데모실행.bat" 파일을 더블클릭
  2. 검은 창이 뜨고 "Starting the server..." 메시지가 나옴
     - 처음 한 번은 "installing dependencies..." 로 1~2분 걸립니다 (인터넷 필요)
  3. 잠시 뒤 기본 브라우저가 자동으로 http://localhost:3000 을 엽니다
     - 안 열리면 브라우저 주소창에 직접 입력:  http://localhost:3000


■ 종료
  - 검은 창을 그냥 닫으면 서버도 함께 종료됩니다


■ 시연 팁 (지금은 AI 파이프라인 연동 전 단계)
  - 캔버스 편집 기능이 핵심 시연 포인트:
    · 왼쪽 팔레트에서 요소 클릭 → 배치
    · 드래그로 이동, 모서리 점으로 크기 조절
    · Shift+클릭 또는 빈 곳 드래그로 여러 개 선택 → 상단 정렬/분배 버튼
    · Ctrl+G 로 그룹, 우클릭으로 메뉴
    · 우하단 "?" 버튼에 단축키 모음

  - "화면 생성" 버튼 시연:
    · 보충 설명(왼쪽 아래 입력칸)에  폴백  이라고 입력하고 생성하면
      → 실제 캔버스 배치가 WebSquare XML + 미리보기로 변환되어 나옵니다
      (AI 정리는 없지만 결정론적 변환기가 동작)
    · 보충 설명에  질문  이라고 입력하면 → 질문 응답 UI 시연


■ 나중에 (담당 1이 AI 파이프라인을 붙인 뒤)
  - 이 데모실행.bat 은 그대로 씁니다. (서버 실행 방식·주소 동일: http://localhost:3000)
  - git pull 로 최신 코드를 받으면 bat 이 필요한 라이브러리를 알아서 다시 설치합니다.
  - 실제 AI 를 쓰려면 프로젝트 폴더에 .env 파일이 필요합니다:
      .env.example 을 복사해 .env 로 저장 → ANTHROPIC_API_KEY 값 입력
    .env 가 없어도 서버는 뜨고, "화면 생성" 은 결정론적 변환기로 동작합니다(시연 가능).


■ 문제가 생기면
  - "Node.js not found" → Node.js 를 설치하고 다시 실행
  - 검은 창이 바로 닫힘 / 서버가 즉시 종료 → 폴더에서 한 번 "npm install" 실행 후 다시
  - 브라우저에 "연결할 수 없음" → 검은 창에 서버 메시지가 다 뜰 때까지 기다린 뒤 새로고침
  - 포트 충돌(다른 서버가 이미 3000 사용 중) → 이전에 띄운 검은 창을 닫고 다시 실행
