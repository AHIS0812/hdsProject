## 0. 한 줄 요약

`/api/generate` → `src/pipeline/deterministic.js` (규칙 기반 변환기) → 결과 모달, 전 구간 동작한다.
외부 LLM은 쓰지 않는다. 남은 일은 **매핑 값 정합**(사내 표준 확인)과 **선택 과제**(`runs/` 저장, 시스템별 override)뿐이다.

## 1. 현재 동작

### 1.1 완료

- **`/api/generate`** (`src/server/routes/generate.js`): `screen-draft` 스키마 검증 → `deterministicResult(payload)` → `elapsedMs` 측정 → 반환. 예외 시 `status:'error'`.
- **규칙 기반 변환기** (`src/pipeline/deterministic.js`):
  - 읽기 순서 정렬 (`readingOrder`)
  - 필수(＊) 라벨 → 인접 필드 전파 (`propagateRequired`) → `mapping.json` 의 `requiredClass`
  - `area` 포함 관계 트리 (`buildContainmentTree`) → `<w2:group>` 자식 중첩
  - 태그 변환 (`shapeToXml`) — select/radio→`<option>`, list→`<w2:gridColumn>`, tab→`<w2:tabItem>`
  - Preview HTML (`buildPreviewHtml`) — 좌표 그대로의 와이어프레임
  - 순수 함수 다수 export (`computeAlign` 은 프론트 것, 여긴 `readingOrder`/`propagateRequired`/`buildContainmentTree`/`shapeToXml`/`compileDeterministic`/`deterministicResult`)
- **메타 API** (`src/server/routes/meta.js`): `/api/systems`, `/api/screens?system=&q=`, `/api/screens/:id` — `src/server/fixtures.js` 가 `fixtures/` 를 읽는다.
- 단위 테스트: `test/deterministic.test.js`, `test/schemas.test.js`. CI 스모크(`.github/workflows/ci.yml`)가 `/api/generate` → `"converter":"deterministic"` 확인.

## 2. 계약 (스키마) — 유지할 것

`schemas/` 2종. 필드 추가는 무해, **제거·의미 변경·enum 축소는 프론트와 동시 수정**.

| 스키마 | 방향 | 프론트 의존 |
|---|---|---|
| `screen-draft.schema.json` | 프론트 → 백엔드 | 에디터가 생성. `type` enum 16종, `mode`/`template`/`baseScreen`, shape `id/x/y/w/h/label?/items?/required?/group?/src?`(image=data URL) |
| `generation-result.schema.json` | 백엔드 → 프론트 | 결과 모달이 소비. **§2.1 참조** |

### 2.1 `generation-result` — 프론트가 읽는 필드

```jsonc
{
  "status": "ok" | "error",              // 필수

  // status=ok
  "preview": { "html": "..." },           // [화면] 탭 iframe srcdoc. 자기완결형 HTML (외부 리소스 불가)
  "code": {
    "websquareXml": "<w2:group ...>",     // [WebSquare XML] 탭 (구문 강조), 복사
    "files": [ { "path": "screen.xml", "content": "..." } ]   // 2개↑ → 내려받기가 zip
  },

  // status=error
  "error": { "message": "...", "log": "..." },   // <pre> 로 노출, 복사·내려받기 버튼 숨김

  // 항상 (선택)
  "report": {
    "converter": "deterministic",
    "elapsedMs": 3,                        // >=50 이면 "N.N초", 아니면 "즉시" 표기
    "propagatedRequired": 2,               // 상태줄에 "필수 표시 N건 자동 반영"
    "unresolved": [], "note": "..."
  }
}
```

- [화면] 탭 "이미지 복사"는 프론트가 `preview.html` 을 html2canvas 로 캡처. [XML] 탭 "복사"는 텍스트.

## 3. 참고 자원

| 경로 | 내용 |
|---|---|

| `test/deterministic.test.js` | 변환기 단위 테스트 (읽기순·매핑·필수 전파·area 중첩) |

## 4. 빠른 시작 · 검증

```bash
npm install
npm run dev            # http://localhost:3000
npm test               # 단위 테스트
node scripts/run-eval.mjs   # 평가 케이스 배치 → runs/<ts>/
```

- `.env` 는 `PORT` 만 (없어도 됨).
- 매핑 값을 바꾸면 `test/deterministic.test.js` + `docs/03_평가결과.md` §3 갱신.
- 스키마를 바꾸면 프론트(`src/web/js/result-modal.js`, `editor.toPayloadShapes`)와 동시에.
