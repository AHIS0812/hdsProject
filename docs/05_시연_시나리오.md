# 하이스케치 PoC — 시연 시나리오

| 항목 | 내용 |
|---|---|
| 대상 | 기획/PM/이해관계자 대상 데모 (10~15분) |
| 준비물 | `데모실행.bat`, 크롬(또는 엣지) |
| 현재 단계 | 담당 2(에디터·통합·계약) 완료 · 담당 1(AI 파이프라인) 착수 전 |
| 관련 | [개발지시서](01_개발지시서.md), [1차 평가](03_평가결과.md), [담당 1 인수인계](04_담당1_인수인계.md) |

> **핵심 메시지**: "러프하게 그린 화면 스케치 → 사내 표준 WebSquare 화면·코드로 자동 정리." 오늘은 **에디터와 데이터 흐름**을 보여준다. AI 정리 단계는 다음(담당 1).

---

## 0. 시연 5분 전 준비

1. `데모실행.bat` 더블클릭 → 검은 창에 `AI Screen Draft → http://localhost:3000`, 브라우저 자동 오픈
2. 화면이 예전 테스트 상태로 열리면 상단 **비우기** 클릭, 왼쪽에서 시스템·유형 다시 선택 (또는 브라우저 새로고침)
3. 브라우저 확대(Ctrl + `+`) 1~2단계 — 뒤에서도 보이게
4. 결과 모달이 잘 뜨는지 1회 예행: 보충 설명에 `폴백` 넣고 **화면 생성** → 모달 확인 → 닫기 → **비우기**

---

## 1. 문제 제기 — 30초 (말로)

- WebSquare 화면 1개를 편집기에서 직접 만들면 통상 **25~40분** (레이아웃 잡고, 표준 컴포넌트 찾아 넣고, 필수·정렬 규칙 맞추고…).
- 기획자가 "이런 화면" 스케치는 빠르게 그리지만, 그걸 개발 표준으로 옮기는 게 병목.
- 이 PoC의 가설: **캔버스에 러프하게 그린다 → AI가 사내 표준으로 정리한다 → WebSquare XML까지 뽑는다.**

---

## 2. 에디터로 화면 그리기 — 4분

> "먼저 기획자가 화면을 그리는 부분입니다."

| 순서 | 할 것 | 말할 것 |
|---|---|---|
| 2-1 | 왼쪽 **시스템** = 하이포탈 선택 (검색 가능) | "대상 시스템을 고릅니다. 시스템별로 표준이 다를 수 있어서 먼저 선택." |
| 2-2 | **신규 화면** → 유형 **등록 · 수정** 클릭 | "새로 만들 화면이면 유형을 고르면 기본 골격이 깔립니다. (변경 화면이면 기존 화면을 불러와 수정)" |
| 2-3 | 왼쪽 팔레트에서 **입력칸 / 선택 / 날짜** 클릭 → 캔버스에 배치 | "요소는 클릭하면 놓입니다. 16종." |
| 2-4 | 요소를 **드래그로 이동**, **모서리 점으로 크기 조절** — 분홍 스냅 가이드 보여주기 | "반듯하게 안 그려도 됩니다. 정렬은 뒤에서 AI가 잡아줍니다." |
| 2-5 | 요소 클릭 → 위에 뜨는 **플로팅 툴바**에서 문구 입력, **＊(필수)** 토글 | "라벨·필수 여부·항목을 여기서 바로 고칩니다." |
| 2-6 | 요소 2개 **Shift+클릭** → 툴바에서 **왼쪽 정렬**, (3개 이상) **균등 분배** | "여러 개 선택하면 정렬·분배가 됩니다." |
| 2-7 | 2개 선택 → **Ctrl+G** (그룹) → 드래그하면 같이 이동 → **Ctrl+Shift+G** 해제 | "묶어서 다루고 싶으면 그룹." |
| 2-8 | 요소에서 **우클릭** → 복제 / 삭제 메뉴 | |
| 2-9 | **Ctrl+Z**(되돌리기), 하단 **줌** 버튼, 우하단 **?**(단축키 도움말) | "60단계 되돌리기, 확대·축소, 단축키 안내." |
| 2-10 | 상단 화면 이름칸에 **"계약자 등록"** 입력 | "신규 모드에서는 화면 이름을 직접. 변경 모드면 불러온 이름 고정." |

> 자동 저장 표시("저장됨")를 짚어주면 좋음 — 새로고침해도 유지.

## 3. 화면 생성 — 3분 (하이라이트)

| 순서 | 할 것 | 말할 것 |
|---|---|---|
| 3-1 | 왼쪽 아래 **보충 설명**에 입력: <br>`주민번호는 필수, 등록일은 오늘로 기본값` <br>그리고 같은 칸에 `폴백` 추가 | "그림으로 표현 안 되는 규칙은 글로 적습니다. (`폴백`은 오늘 시연용 키워드 — 뒤에서 설명)" |
| 3-2 | 참고 파일(Excel·PPT·이미지)도 첨부 가능함을 언급 (드롭존) | "화면정의서 엑셀 같은 걸 붙이면 AI가 항목명을 참고합니다." |
| 3-3 | 상단 **화면 생성** 클릭 → 진행 단계 표시 | "요청이 백엔드로 갑니다. 스키마 검증 → (AI 단계) → 코드 변환 → 자동 검증." |
| 3-4 | 결과 모달 **[화면]** 탭 — 미리보기 | "그린 대로 화면이 나옵니다." |
| 3-5 | 상단 **동시 보기** 전환 — 내 스케치 ↔ 생성 결과 나란히 | "왼쪽이 내가 그린 것, 오른쪽이 정리된 결과. 변경 전후 비교용." |
| 3-6 | **[전달 데이터]** 탭 | "이게 기획자 화면 → AI로 넘어가는 데이터. 두 팀의 계약(JSON 스키마)입니다." |
| 3-7 | **[WebSquare XML]** 탭 — 구문 강조된 XML | "표준 컴포넌트로 변환된 코드. `area` 안에 요소가 묶이고, 필수 항목엔 essential 클래스가 붙습니다." |
| 3-8 | 상단 **이미지 복사** / **↓ 내려받기** | "화면은 이미지로 클립보드에, 코드는 파일로. (파일 여러 개면 zip)" |
| 3-9 | 하단 상태줄: **"✓ 생성 완료 (결정론적 변환 · AI 정리 없음)"** 짚기 | **여기서 현재 상태를 솔직히**: "지금은 AI 연동 전이라, 규칙 해석·표준 정리 없이 **기계적으로만** 변환한 결과입니다. 그래서 `폴백` 키워드를 넣었습니다. AI가 붙으면 이 자리에서 필수·기본값·레이아웃 정리까지 됩니다." |

## 6. 현재 상태와 다음 — 1분 (말로)

- **완료(담당 2)**: 캔버스 에디터 전체, 두 팀 데이터 계약(스키마), 결과 모달, 결정론적 변환기, 반응형·접근성, 1차 평가, 테스트·CI.
- **대기(담당 1)**: AI 파이프라인 — 러프 좌표 → 표준 정리(IR) → WebSquare 코드 → 자동 검증. `docs/04_담당1_인수인계.md`에 착수 지점 정리됨.
- **검증 계획**: 오늘 본 "결정론적 변환"이 **하한선**. AI가 이걸 넘어서 얼마나 "쓸 만한 초안"을 주는지 신규 6종 + 변경 2종으로 2차 평가 (`docs/03`).

## 부록 A. 예상 질문 대응

| 질문 | 답 |
|---|---|
| AI 정리는 언제 보나요? | 담당 1 착수 → 2차 평가에서 케이스별로 검증해 보고. |
| 실제 사내 WebSquare 표준 반영됐나요? | 아직 외부 공개 자료 기준(OI-3). 컴포넌트 클래스명 등은 사내 표준으로 확정 필요 — 인수인계 문서에 명시. |
| 실제 화면정의 데이터로 돌려도 되나요? | 상용 LLM 전송·보관 정책 확인 전까지는 금지(OI-7). PoC는 외부 공개 샘플만. |
| 왜 React가 아니고 바닐라 JS? | 빌드 없이 바로 뜨는 걸 우선(OI-2). 예시 프로토타입 계승. 정식 개발 때 재검토. |
| 변경 화면(기존 화면 수정)도 되나요? | 됩니다. 시스템 선택 → 변경 화면 → 화면 검색 → 불러오면 기존 배치가 캔버스에. baseScreen 대비 변경분 해석은 AI 단계(A-4). |
| 첨부(엑셀)는 어떻게 쓰이나요? | 텍스트·표를 추출해 AI 컨텍스트로. 레이아웃 재현은 아님(OI-8). |
| 생성 시간은? | 결정론적 변환은 즉시. AI+자동검증 포함 목표는 3분 이내(AC-13), 2차 평가에서 실측. |

## 부록 B. 장애 대응

| 증상 | 조치 |
|---|---|
| 브라우저가 안 열림 | 주소창에 직접 `http://localhost:3000` |
| "포트가 이미 사용 중" / 서버가 안 뜸 | 이전에 열어둔 검은 창을 닫고 `데모실행.bat` 다시 실행 |
| 생성 결과가 이상함 | 모달 닫고 **비우기** → 다시. 또는 브라우저 새로고침(자동 저장으로 복원됨) |
| 캔버스가 예전 상태 | 상단 **비우기**, 시스템·유형 다시 선택 |
| "Node.js not found" (검은 창) | 시연 PC에 Node.js LTS 설치 필요 (https://nodejs.org) |
| 단축키가 안 먹음 | 캔버스를 한 번 클릭해 포커스를 준 뒤 다시 |

## 부록 C. 시연 안 하는 게 나은 것

- **XML을 실제 WebSquare에 붙여 실행** — 대상 버전·스키마 미확정(OI-3). "코드가 나온다"까지만.
- 대량/실데이터 — 정책 미확정.
- AI 품질 비교 — 아직 AI 없음.
