# 사내 UI 표준 — 레이아웃 가이드 (PoC용 최소)

> 개발지시서 §9, T-4. 대상 화면 유형 4종에 필요한 범위만. 외부 공개 수준으로 직접 정의(사내 실자산 반입 금지).

## 그리드
- 12 컬럼 기준, 기본 간격 `token.space.md`(12px).

## 화면 유형별 템플릿
| 유형 | 구성 |
|---|---|
| list (목록 조회) | 상단 조회 영역(area) → 조회/초기화 버튼 우측 정렬 → 결과 그리드(gridView) |
| detail (상세 조회) | 조회 영역 → 상세 영역(area, 라벨-입력 2열) |
| form (등록·수정) | 섹션 제목 → 입력 영역(필수 표시) → 하단 저장/취소 버튼 우측 정렬 |
| popup (팝업) | 팝업 제목 → 검색 영역 → 결과 그리드 → 선택/닫기 버튼 |

## 버튼 규칙
- 조회/검색: `token.color.primary`
- 저장/요청/확정/선택: `token.color.accent`
- 우측 정렬, 주요 액션이 오른쪽 끝.

## 필수 입력
- 라벨 앞 `＊`, 색상 `token.color.required`.
- WebSquare: `class="w2input_essential"`.
